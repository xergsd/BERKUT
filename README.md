# Беркут

Бесконечный 3D-раннер в стиле low-poly на Three.js (r128). Беркут летит над степью, каньоном Чарын и Тянь-Шанем. Очки даются за дистанцию.

## Запуск

ES-модули не работают через `file://`, поэтому нужен любой статический сервер:

```bash
npx serve .            # или
python -m http.server  # затем открыть http://localhost:8000
```

В VS Code можно использовать расширение Live Server. Для деплоя подойдёт GitHub Pages: Settings → Pages → ветка `main`, корень репозитория.

## Структура и зоны ответственности

| Файл | Что внутри | Кто правит |
|---|---|---|
| `index.html` | canvas, HUD, экран старта и Game Over, importmap | визуал (стили) и геймплей (разметка) |
| `config.js` | все числа баланса | геймплей |
| `main.js` | цикл, камера, смена биомов | геймплей |
| `world.js` | бесконечные чанки земли, скалы, столкновения | геймплей |
| `player.js` | управление и полёт беркута | геймплей |
| `game.js` | состояние, счёт, рекорд, HUD | геймплей |
| `visuals.js` | беркут, небо, биомы, постобработка | **только визуал** |
| `assets/` | модели `.glb`, текстуры, звуки | визуал и звук |

## Контракт `visuals.js`

Сигнатуры не менять, внутренности можно менять как угодно.

- `createEagle()` возвращает `THREE.Group`. Нос смотрит в −Z, размах крыльев около 12. Внутри группы `wingL` и `wingR` (задать через `name` или `userData`) с точкой вращения у плеча.
- `createSky(scene)` возвращает `{ update(playerPos, timeOfDay01) }`. Функция должна сохранить себя в `scene.userData.sky`.
- `BIOMES` — массив объектов `{ name, fog, skyTop, skyMid, ground: [4 цвета], rock, sun }`.
- `applyBiome(scene, i, t)` плавно переходит от биома `i-1` к биому `i`, где `t` от 0 до 1.
- `createPostFX(renderer, scene, camera)` возвращает `{ render(), setSize(w, h) }`.

## Управление

Мышь или палец — направление полёта. Также работают WASD и стрелки. Shift или второй палец — рывок. Пробел или клик запускают игру и рестарт.

## Очки, рывок и рекорд

- **Очки** начисляются за каждый метр. Множители перемножаются.
- **Низкий полёт:** ниже 10 м над землёй очки за дистанцию ×1,5.
- **Рывок:** пока зажат Shift (на телефоне — второй палец), беркут летит в 1,5 раза быстрее, а очки за дистанцию ×1,5. Рывок тратит выносливость: полной полоски хватает на 4 с. Без рывка полоска восполняется за 8 с. Если она опустела, для нового рывка нужно отпустить Shift.
- **«Близко!»:** пролёт в пределах 6 м от скалы даёт 100 очков. Каждый трюк подряд добавляет +0,5 к множителю комбо (максимум ×4). Комбо умножает и очки за трюк, и очки за дистанцию. Если за 3 с не сделать следующий трюк, комбо сгорает.
- **Рекорд** — забег с лучшими очками. Вместе с очками показывается его дистанция.

Все числа лежат в `config.js`.

## Что уже работает

- бесконечная земля
- скалы, которые с дистанцией стоят плотнее и чаще появляются «на линии» игрока
- рост скорости
- столкновения, Game Over и рестарт
- рекорд (очки и дистанция лучшего забега) в localStorage
- очки, бонус за низкий полёт, трюк «Близко!», комбо
- рывок на Shift и выносливость
- 4 биома с плавным переходом каждые 1500 м
